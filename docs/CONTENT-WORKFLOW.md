# Flujo de contenido

1. Recibir texto, media y fuente de verificación.
2. Clasificarlo por dominio: solución, producto, industria, empresa o caso.
3. Registrar un ID y slug estables; el diseño no debe usarse como fuente de identidad.
4. Incorporar alt text y estado de autorización de publicación.
5. Componer la ruta con campos opcionales; una sección sin evidencia no se renderiza.
6. Activar navegación, sitemap e indexación únicamente al completar el mínimo comercial.

## Mínimo para un caso de éxito

- título y sector aprobados;
- reto operativo;
- alcance realizado por Tecno All;
- servicios y tecnología realmente utilizados;
- al menos una imagen autorizada;
- resultado cualitativo verificable o métrica aprobada;
- autorización explícita para publicar cliente/marca cuando corresponda.

Sin estos elementos, el caso permanece en datos internos y no genera URL pública.
