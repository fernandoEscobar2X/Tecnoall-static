# Mapa de rutas públicas

| Ruta                      | Responsabilidad                     | Publicación                       |
| ------------------------- | ----------------------------------- | --------------------------------- |
| `/`                       | Síntesis comercial y conversión     | Navegación y sitemap              |
| `/soluciones/`            | Índice de capacidades               | Navegación y sitemap              |
| `/soluciones/[slug]/`     | Detalle por solución                | Sitemap                           |
| `/marcas/`                | Ecosistema de fabricantes           | Navegación y sitemap              |
| `/productos/`             | Familias de producto y cotización   | Navegación y sitemap              |
| `/empresa/`               | Identidad, sedes y formulario       | Navegación y sitemap              |
| `/casos-de-exito/`        | Evidencia y fotografías autorizadas | Navegación y sitemap              |
| `/casos-de-exito/[slug]/` | Compatibilidad de enlaces de casos  | No indexada como detalle autónomo |
| `/contacto/`              | Rutas de contacto                   | Accesible, consolidada en empresa |
| `/industrias/`            | Contextos industriales preparados   | Accesible, fuera de sitemap       |
| `/industrias/[slug]/`     | Aplicaciones por contexto           | Accesible, fuera de sitemap       |

No existen rutas `/tienda/`, `/admin/` ni `/api/` en este artefacto.

## Regla de publicación

Una ruta entra a navegación e indexación únicamente con contenido comercial suficiente y aprobado.
La existencia técnica de un archivo no equivale a autorización de publicación.
