# Recursos oficiales de Tecno All

Este directorio contiene únicamente medios locales autorizados para la experiencia corporativa. Las fotografías, capturas de proyectos y logotipos corresponden a material real de Tecno All; Astro genera derivados optimizados durante el build sin sobrescribir los archivos fuente.

- El brochure corporativo se sirve localmente desde `public/brochure-tecnoall.pdf`.
- Los logotipos normalizados viven en `logos-transparent/`.
- El contenido estructurado que consume el sitio vive en `src/content/`.

Los masters originales deben conservarse y cualquier sustitución futura deberá partir de material aprobado por Tecno All.
